[377] Heading 1: 5. Security
[378] Heading 2: 5.1 Authentication Flow
[379] Heading 3: 5.1.1 JWT + Refresh Token
[381] normal: Alur refresh token:
[382] normal: Client request ke /v1/auth/refresh dengan refresh token
[383] normal: Server validasi refresh token di Redis (belum expired, belum dipakai)
[384] normal: Server issue access token baru + refresh token baru (rotate)

[386] normal: Server return access token baru + set refresh token baru di cookie
[388] Heading 3: 5.1.2 Role-Based Access Control (RBAC)
[390] Heading 2: 5.2 Security Checklist Backend
[392] Heading 3: 5.2.1 Input Validation & Injection Prevention
[393] normal: Semua input divalidasi menggunakan go-playground/validator sebelum masuk ke service
[394] normal: TIDAK pernah string concatenation untuk query SQL ΓÇö selalu gunakan parameterized query
[395] normal: Sanitasi input teks bebas yang akan ditampilkan di FE (HTML escape)
[396] normal: Validasi ukuran dan tipe file upload (image only, max 5MB)
[398] Heading 3: 5.2.2 Rate Limiting
[399] normal: Global rate limit: 100 request per menit per IP
[400] normal: Auth endpoints: 5 percobaan login per menit per IP (lebih ketat)
[401] normal: Payment webhook: whitelist IP dari payment gateway
[403] Heading 3: 5.2.3 HTTP Security Headers
[404] normal: Strict-Transport-Security: max-age=31536000 (HSTS)
[405] normal: X-Content-Type-Options: nosniff
[406] normal: X-Frame-Options: DENY
[407] normal: Content-Security-Policy: disesuaikan
[408] normal: Referrer-Policy: strict-origin-when-cross-origin
[410] Heading 3: 5.2.4 CORS
[411] normal: Whitelist hanya domain FE yang diizinkan (bukan *)
[412] normal: Credentials: true hanya untuk domain yang sudah diverifikasi
[413] normal: Expose headers terbatas

[416] normal: Password: bcrypt dengan cost factor 12
